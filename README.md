# yorch.github.io — Jorge Barnaby

Personal portfolio and curated open-source showcase for Jorge Barnaby (`yorch`), Principal Software Engineer at SentinelOne, based in Miami, FL.

**Live site:** <https://yorch.github.io/>

Built with Astro and Tailwind CSS. The site uses a consistent terminal-inspired visual style while keeping portfolio content statically rendered and discoverable. It includes an elevated highlighted-project section, a filterable/sortable project grid, and a `⌘K` / `Ctrl+K` command palette.

## Local development

Requirements: Bun (version pinned in `package.json`) and Node 26 (see `.node-version`).

```bash
bun install
bun run dev                 # http://localhost:4321
bun run generate:projects   # refresh GitHub metadata (GITHUB_TOKEN recommended)
bun run build
bun run preview             # preview dist/
bun run lint                # Biome lint
bun run lint:fix            # Biome check --write
bun run typecheck
bun run curate:list         # inspect curation
```

## Curation

Edit `src/data/curation.json`:

- `highlighted`: elevated projects above the regular grid.
- `featured`: ordered projects pinned ahead of the remaining grid.
- `hidden`: excluded projects unless `visible` is configured.
- `visible`: optional non-empty allowlist.
- `overrides`: custom per-project description and homepage values.

`src/data/projects.json` is generated by `scripts/generate-projects.ts`; normally do not edit it by hand.

## Deployment and contribution workflow

GitHub Actions builds and deploys to GitHub Pages on pushes to `master` and refreshes repository data daily. Workflow actions and dependencies are pinned; preserve those pins when updating tooling.

**Do not push directly to `master` or merge without approval.** Make changes on a feature branch, run the checks, push the branch, and open a pull request for review.
